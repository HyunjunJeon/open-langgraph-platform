# API 레퍼런스 (한글)

이 프로젝트의 API 레퍼런스는 실행 중인 서버의 OpenAPI 스키마가 단일 소스입니다.

## 로컬 (권장)

- Swagger UI: `http://localhost:8000/docs`
- OpenAPI JSON: `http://localhost:8000/openapi.json`

## 스펙/참고

- Agent Protocol 스펙: `https://github.com/langchain-ai/agent-protocol`
- LangGraph 문서: `https://langchain-ai.github.io/langgraph/`

이 문서는 다른 문서에서 안정적으로 링크하기 위한 포인터입니다.
